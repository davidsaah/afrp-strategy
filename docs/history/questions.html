Open questions

Everything still undecided, each with a number, an owner and the goal and branch it affects.

How to use this page

Every open question is in the tables below. Each row gives the question, what the record already knows about it, who owns the answer, the goal and branch it affects, and where it came from. Use the two menus above the tables to show only the questions for one goal or one branch, and the owner box to show only the questions whose owner contains a word (for example "David" or "ARFECF Board"). The two lists further down this section group the owners most often asked for.

Since 4 October 2026 (D99) every question carries a status: open; answered for now, where a decision holds for now and the lasting answer is still open; answered in part; pending an act, where the platform's answer is set and a body's act is awaited; parked, where no slice of the master plan and no gate in a design note cites it, so it holds no build; or answered. The open ones are grouped into twelve clusters (A to L), each put to its owning body as one ask; the rest follow, then the parked list, then the answered list. What the decisions already settle, topic by topic, is on Rules in force.

The platform never fills a gap itself. Where the by-laws and the decisions are silent, the part of the platform that depends on the answer waits for it, and the question here names who must give it.

How to take part

Every question has a Q-number, and the same number is used everywhere it is discussed (D43).

  • The build team discusses on GitHub: each row's Discuss link searches the repository's Discussions for that number. If nothing is there yet, start a discussion with the Q-number in its title.
  • The Strategic Planning Committee comments in its own working draft, citing the Q-number. That draft is behind this page in places; how the two are brought level is Q-235.
  • To raise a new question, start a GitHub discussion, or add a comment in the committee's draft, saying what is undecided and who you think should decide it. It is given the next free Q-number when it is added to the record. A question that only asks an existing one again is added to that row instead.
