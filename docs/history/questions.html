Open questions

Everything still undecided, each with a number, an owner and the goal and branch it affects.

How to take part

Every question has a Q-number, and the same number is used everywhere it is discussed (D43).

  • The build team discusses on GitHub: each row's Discuss link searches the repository's Discussions for that number. If nothing is there yet, start a discussion with the Q-number in its title.
  • The Strategic Planning Committee comments in its own working draft, citing the Q-number.

When a question is answered, the answer is written into the Decisions Register as a D-number, and the question moves to the Answered list at the end of this page, keeping its number. Questions are kept in site/data/questions.yaml.
