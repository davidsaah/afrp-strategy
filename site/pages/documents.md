These are the Strategic Planning Committee's own documents. Each title links to
the file in the Federation's shared drive. **The links open only for people with
access to AFRP's drive**; anyone else will be asked to request access.

This page carries a short summary of each document and never its text, because
several of them name living people (D50). The tag under each title is the short
name the [crosswalk](crosswalk.html) uses for it.

Committee rosters and contact lists are kept in the same drive and are
deliberately not listed here.
